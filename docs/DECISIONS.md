# DECISIONS — judgment calls made during the build

Format: date · decision · why · how to change it

- 2026-11-02 · Next.js 16.4 with its default `cacheComponents: true` kept · it's the scaffold default, and a static app shell gives a fast PWA · set `cacheComponents: false` in `next.config.ts`.
- 2026-11-02 · App screens are client components that read/write Supabase directly via the browser client; RLS is the security boundary; economy changes go only through `security definer` RPCs · fits a static PWA shell, enables optimistic UI and offline handling, and avoids blocking server renders on cookies · move reads into Server Components behind `<Suspense>` if SSR data is ever needed.
- 2026-11-02 · next-intl used in client mode (`NextIntlClientProvider`), locale stored in localStorage + `profiles.locale` (synced across devices after login) · no locale in the URL; works with the static shell · switch to next-intl routing (`app/[locale]`) if public SEO pages are ever needed.
- 2026-11-02 · Vercel CLI runs via `npx vercel` · global npm install failed with a permissions error and fixing it needs sudo · `brew install --cask vercel` or fix npm prefix.
- 2026-11-02 · Auth: email magic link only for now; Google OAuth deferred to M14 (per START_HERE) · Google needs Google Cloud console setup · add provider in Supabase + button flag `NEXT_PUBLIC_GOOGLE_AUTH=1`.
- 2026-11-02 · Keep-alive: Vercel daily cron calls `/api/keepalive`, which runs a tiny DB RPC · Hobby plan allows 1 cron/day; a DB query counts as activity · change schedule in `vercel.json`.
- 2026-11-02 · Login email contains both a magic link AND a 6-digit code; the login screen accepts the code · on iOS, the home-screen PWA and Safari have separate storage, so a magic link opened from Mail signs in Safari, not the installed app (iOS restriction) · remove the code step in `app/login` and the template in `supabase/templates/` if iOS ever shares sessions.
- 2026-11-02 · G6 "Lighthouse PWA ≥ 90" is checked by `tests/e2e/pwa.spec.ts` (manifest, icons, service worker, apple-touch-icon) instead of a Lighthouse score · Lighthouse 12+ removed the PWA category, so the score no longer exists · re-add if Lighthouse brings it back.
- 2026-11-02 · Fixed test clock is 2026-10-28 10:00 Bangkok (a Wednesday), in the past · Supabase JWTs are issued at real time; a future fake clock makes the client think tokens expired · change `tests/helpers/clock.ts`.
- 2026-11-02 · Playwright pinned to 1.61.1 · this Mac runs macOS 14, where Playwright only ships a frozen WebKit build; 1.62+ sends a WebKit setting that build doesn't know, so every WebKit test crashes · unpin after upgrading macOS (CI on Ubuntu is unaffected).
- 2026-11-02 · Replaced the "6-digit code" email template with a "paste the sign-in link" box on the login screen (it also still accepts a code) · Supabase free plan refuses custom email templates without custom SMTP, and the default email has only a link. The pasted link's token is verified inside the app, so the iOS home-screen app signs in without Safari · to get a code in the email: add free SMTP (e.g. Gmail app password or Resend) in Supabase, then restore a template with `{{ .Token }}`.
- 2026-11-02 · Supabase project `twentyfour-seven` created in the "Pinto" org (free), not the Exsim org · this is a personal app; keeps it separate from Exsim's work project · move with Supabase "Transfer project".
- 2026-11-02 · Default Supabase email only delivers to the org's team members, about 2 emails/hour · fine for Minnie's personal use; custom SMTP is needed before inviting other users (M14).
- 2026-11-02 · Repo-local git identity set to GitHub no-reply `104623932+Nck189@users.noreply.github.com` · Vercel blocks Git deploys when the commit author isn't a GitHub account (the machine default was `…@MacBook-Air.local`) · `git config user.email` in this repo.
- 2026-11-02 · Vercel builds only `main` (`ignoreCommand` in `vercel.json`); PR branches are skipped · Preview has no Supabase env (build fails at prerender), and a preview would hit the prod DB before its migrations are applied · GitHub Actions QC is the PR gate; to get previews, add Preview env vars pointing at a separate Supabase project and remove `ignoreCommand`.
- 2026-11-02 · Stress workflow runs CJ-15 with QC's parallelism (2 workers × 24 repeats, no retries), not 8 workers · at 8 workers the hosted runner starved WebKit: 12/192 failures were clicks stuck on "waiting for element to be stable" and "WebKit encountered an internal error" (Chromium 0 failures), i.e. the runner, not the app · raise workers only on a bigger runner.
- 2026-11-02 · Compression order is Free → Gradation → Focus → **Work (≥ 50%)** → Down → Wake → Sleep; Work isn't compressed on a day with a fixed event in Work · Minnie (review M2-F3): shrink Work before sleep, except days with class/morning appointments, "with balance" → the 50% floor keeps a real Work block · change `WORK_MIN_SHARE` in `lib/engine/plan.ts`.
- 2026-11-02 · An early "I'm up" (up to 3 h before target) keeps earning the Sunrise ticket · Minnie confirmed (review M3-F10) · `press_wake()` window.
- 2026-11-02 · Offline check-ins, step 1: failed saves retry by themselves on the browser `online` event ("Try again" stays as a fallback) · Minnie found offline saves don't stick and left the choice to Claude · step 2, a persistent offline queue that survives closing the app (IndexedDB + replay + conflict rules), is added to M14 "error and offline states".
