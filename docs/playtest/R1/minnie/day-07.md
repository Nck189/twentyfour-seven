How I feel: annoyed, not guilty. Because:
- **โฟกัส died from the schedule bug.** The app put Focus at 08:00–09:30 (overlapping class or my commute) and I never "started" it, so it counted as "พลาด" every day. I *did* focus: I did the slides at 08:00 in the library on day 5, but the task wasn't on Today, so there was nothing to tick.

Harvest of the radish: **"คุณภาพ: ปริซึม · มูลค่า ×6"** → **"+1 แรดิช"**. Coins stayed at 100. Same with the cow tonight: **"เก็บนม"** → **"+1 นม"**, coins 50 → 50.
