## Checked and OK
- **`delete_my_account`:**
  - It is `security definer` with `search_path = ''`, raises 42501 when `auth.uid()` is null, and deletes only `where id = uid`.
  - It is revoked from `public` and `anon`; anon gets an error (integration test).
  - It is not CSRF-able. PostgREST needs the `Authorization: Bearer` header (no cookie auth), and a volatile RPC is POST-only.
  - A retry after a lost response is a no-op success.
  - No trigger on `events` or any other table blocks the cascade.
  - The integration test proves every `EXPORT_TABLES` table is empty for the user afterwards, and another user's rows survive.
- **Delete UX:**
  - It takes two steps. Cancel and Confirm are disabled while it runs, and an error shows `role="alert"` and keeps the dialog.
  - `signOut({scope:"local"})` succeeds for a deleted user (auth-js ignores 403/404), then `location.replace('/login')`.
- **Admin page:**
  - `retentionServer.ts` is `server-only`. It uses `auth.getUser()` (verified with the auth server, not `getSession`).
  - `ADMIN_EMAILS` is split on commas, trimmed, lowercased and empty entries dropped. An empty or unset value admits nobody, and comparing a null email fails.
  - Nothing references `ADMIN_EMAILS` with `NEXT_PUBLIC_`, in `next.config` or in client code.
  - The service-role client is only in `lib/supabase/admin.ts` (`server-only`).
  - `notFound()` runs before any data is rendered.
  - The RSC payload carries only `{week, n, rate}` and a total count: no ids, emails or timezones.
  - `connection()` makes the page dynamic (no prerender or data cache), and it is `robots: noindex`.
- **Offline queue:**
  - The storage key is per user id, and every stored row carries `user_id`. RLS `with check` stops a tampered or other-user op (probe: 42501), so a user can only hurt their own rows.
  - The stored `event` goes through `logEvent` and the server's events deny list.
  - Quota or blocked storage is caught, and the in-memory queue still works.
  - The 7-day cap holds, and malformed entries and bad JSON are dropped.
  - Restore runs once per hook. A StrictMode or cancelled load returns before `restoredRef` is set.
  - Restore happens before the merge, so restored keys are "busy" and keep the pending `next`.
  - Realtime and refetches don't overwrite queued keys.
  - Order within one `retrySave` is kept, and a partial failure re-queues the rest in order.
  - `useToday` has a single consumer (`TodayScreen`), so two hook instances never replay the same store.
  - The replay effect and the `online` handler both check `queueRef.current.length`, so a second call doesn't send twice.
- **`actual_min`:**
  - The check is `1..1440`, and `actualChoices` filters to the same range (estimate 1440 → `[720, 1440]`).
  - It uses the existing RLS and `_backlog_server_times` is untouched.
  - The prompt opens only when `complete` returned non-null (RPC success), including `coins = 0`, in Plan and in Today.
  - `actualChoices(30/10/5)`, the median, `overShare` and the per-tag ≥ 3 rule check out by hand.
- **Retention math (pure part):**
  - `weekOf` gives the ISO Monday.
  - Day *k* = sign-up + *k* in the user's own timezone, and only users whose day *k* has come are in the denominator. A cohort with no one due shows `null` → "–".
  - The 120-day window covers D30 for every cohort.
  - The unit test's numbers check out by hand.
  - Ties in the `at` ordering at page boundaries are harmless in practice: rows in the same transaction share the user and the timestamp.
- **UnlockNotice / streak egg:**
  - `egg_hatched` is in the client events deny list, so it can't be forged.
  - The server writes `{species, rarity, unlock: p_id}` (`20261104000000_m9_streak.sql:687`). `streak_7` is the only egg unlock and is granted once, so the lookup returns exactly that row.
  - Species and rarity are validated before the reveal.
  - The pop and spring are off under reduced motion or "skip animations"; the sound plays once per grant set and follows the global mute.
- **Presets:**
  - The unit test plans all 7 weekdays of every starter with no conflict and no short sleep (it passes).
  - Kind names and card texts exist in EN and TH, and the six cards fit a two-column grid with 44 px icons.
- **WeekShare privacy:**
