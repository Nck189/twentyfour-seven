# G7 independent review — M6 (art system + farm scene)
Branch `m6-local` (13 commits 73ff8d4..7d26fdc over `ap-local`). Read-only review: nothing in the repo was changed (`git status` is clean).

## Verdict: **FAIL** (3 open S2, 0 S1)

The farm core is solid:
- The SQL `_plot_ripe` agrees exactly with `lib/game` `simulatePlot`. A randomized fuzz compared 63,700 (plot, day) pairs and found 0 mismatches.
- Clients can't write plots, inventory, decor or server events directly. The RPCs check `auth.uid()`, starter seeds, coins (atomically) and double harvest (row lock).

The S2s are about what feeds the farm, not the RPC plumbing:
- the inputs to "ripe" can be pre-written for future dates
- planned deviations never reach the farm
- the Night-ritual planting step that M4 deferred to M6 was not delivered

## Checked and OK
- **Direct writes:** blocked for plots, inventory, decor (item_id), game_state.coins, and events `harvest`/`seed_planted`/`decor_bought`. RLS errors were verified as `authenticated`.
- **RPC checks:**
  - `plant_seed` refuses non-starter seeds, field slots and busy plots unless `p_replace`.
  - `harvest_plot` refuses unripe crops. Two concurrent harvests produce exactly one inventory +1 and one event (FOR UPDATE). Harvesting twice on the same day fails because of `harvested_on`.
  - `buy_decor` refuses when coins are short and refuses unknown items.
  - `_plot_ripe`, `_wake_day` and `_block_result` aren't executable by `authenticated`.
- **Parity** (counterexample hunt over every branch: open day, weeds + minimum-day clearing, excused vs mode and planned, partial, backfilled, miss_reason, dead at 5, regrow `harvested_on`, ±600/601 s, 60%/70% checklist, backfilled or out-of-window wakes, Night grants): **0 mismatches**. The only divergences are R-M6-5, R-M6-11 and R-M6-12 above.
- **Rules vs SPEC §8.1–8.4:** success = on time ±10 min or ≥ 70% ✓; weeds pause and clear after a minimum day ✓; wilt at 3 and dead at 5 ✓; Vacation/Sick excused ✓; backfill gives no growth or mutations ✓; mutation multipliers stack multiplicatively ✓; rarity grow days 1/2/3/5/7 and uncommon regrow ✓; giants only for pumpkin/melon on 3 adjacent plots ✓. Compost's fertilizer is deferred (K-M6-2, OK).
- **Art lint:** 0. Every dynamic `var(--art-${…})` resolves to an existing token (checked by hand, since the lint can't see template strings). Gradients only in FarmSky. Strokes ≤ 1.4 px, all same-hue tokens.
- **i18n:** 462 keys EN = TH. No hardcoded strings in `components/farm` or art; labels on every plot and decor button. Seed and decor buttons are `min-h-11`.
