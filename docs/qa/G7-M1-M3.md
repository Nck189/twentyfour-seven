## 4. UX budgets (from reading `components/today/*`)

- **CJ-05 check-in: 5 taps.** The current block card is on Today; no navigation is needed. Ticking first-10 auto-starts the block (`useToday.ts:304-339`). Taps: 1 (first-10) + 3 (items) + 1 ("Finish block"). An explicit "Start" tap is optional and would make it 6. With first-10 set to "none", an item tap auto-starts (`set_block_item` sets `started_at`), so 4 taps. A past or other block adds 2 taps ("See the whole day", then the block).
- **"I'm up": 1 tap from launch.** The big button (`WakeCard.tsx:53-80`, `min-h-24`) is visible from 3 h before the target, near the top. Above it there may be the WelcomeCard, one warning, and the night-ritual banner during Sleep (`TodayScreen.tsx:144-197`). Risk: the stale clock after resume or tab switch (R-M3-8). It is double-tap safe (`disabled={busy}`, idempotent RPC).
- **Touch targets:** `Button` `min-h-11 min-w-11`, CheckRow `min-h-12`, Scale 44×44, ⋯ 44×44, Timeline rows `min-h-16`, Sheet Close `min-h-11`. Asserted by `expectTouchTargets` (`today.spec.ts:45, 157`). PASS.
- **Feedback:** `.tap:active` gives an instant pressed state (`app/globals.css`). The WakeCard shows "Logging…" immediately, not after 300 ms (nit).
- **States:** loading and error OK. Empty state unreachable (R-M3-12). Save error banner + "Try again" + auto-retry on `online` OK, but the "Nothing was lost" copy is untrue across an app close (R-M3-9).
- **No dead ends:** Sheet has a visible Close plus Escape (`BlockSheet.tsx`). The reward overlay is tap-to-skip.
